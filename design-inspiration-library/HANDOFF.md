# Design Inspiration Library

## Цель и текущее состояние

Личная русскоязычная библиотека референсов веб-дизайна и айдентики. Она помогает находить работы по визуальному стилю и разбирать, из каких решений складывается их оформление.

Последняя подтверждённая опубликованная версия исходников — [коммит f45ebe0 в ветке `design_library`](https://github.com/mirovif/MGIMO-HACK/commit/f45ebe0) репозитория `mirovif/MGIMO-HACK`. [Папка библиотеки в GitHub](https://github.com/mirovif/MGIMO-HACK/tree/design_library/design-inspiration-library) содержит исходники, а доступность публичного веб-деплоя не подтверждена.

## Что работает

- В библиотеке все 53 изображения и один MP4, фактически найденные в исходной папке. Оригиналы скопированы побайтово, для сетки подготовлены отдельные WebP-превью. Приложенный скриншот с горами визуально совпал с более крупным изображением из папки, поэтому в каталоге одна карточка этого референса.
- Адаптивная сетка в стиле Pinterest, фильтрация по 13 визуальным стилям, поиск, избранное в хранилище браузера, просмотр изображений в масштабе 100% и воспроизведение видео. Стиль назначен по преобладающим признакам изображения. Переданные внешние ссылки сохранены в разделе «Ссылки из подборки».
- При открытии карточки видны название, описание, ключевые метки, тип шрифта, разбор типографики и композиции, три конкретных дизайнерских приёма, пять цветовых образцов с HEX-кодами и копируемый промпт из 5–7 предложений для собственной версии в схожей стилистике.

## Решения и границы точности

- Тип шрифта описывает видимый класс, например узкий гротеск, контрастную антикву или готику. Точные гарнитуры названы там, где они подписаны в работе или подтверждены источником. Остальные названия обозначают визуальные аналоги. Для документальной фотографии отмечено отсутствие самостоятельной наборной типографики.
- Палитры подобраны по визуальным образцам из изображений и отражают основные цвета и акценты. Это приблизительные оттенки, а для видео взят кадр предпросмотра.
- Статическое приложение открывается из файла, сборщик и серверная часть не нужны. Библиотека находится в отдельной папке репозитория, где также есть проект Campus OS. Работать следует в пределах `design-inspiration-library/`. Корневой `HANDOFF.md` посвящён Campus OS.

## Артефакты и перенос

| Файл или папка | Назначение |
| --- | --- |
| [index.html](index.html) | Точка входа и разметка окна референса |
| [styles.css](styles.css), [app.js](app.js) | Адаптивный интерфейс, фильтры, поиск, избранное и просмотр |
| [catalog.js](catalog.js) | 54 записи, идентификаторы стилей, метки и пути к медиа |
| [analysis.js](analysis.js) | Разборы по тем же идентификаторам, включая `fontType` и `palette` |
| [assets/](assets/) | Оригиналы, WebP-превью и локальные шрифты интерфейса |
| [README.md](README.md) | Описание и локальный запуск |

Передать в новый чат этот HANDOFF.md и **папку библиотеки целиком** либо дать подтверждённый доступ к ветке на GitHub. Отдельные исходные вложения для запуска не нужны. Для повторной сверки с исходной коллекцией передать исходную папку отдельно. Её путь на прежнем компьютере — `C:/Users/User/OneDrive/Desktop/Референсы для дизайна`. Избранное хранится в профиле браузера и вместе с файлами не переносится.

## Проверка и следующий шаг

Последнее обновление проверено в Chrome на всех 54 карточках, включая отображение типа и пяти разных HEX-значений в каждой палитре, а также на ширине 320 px. Проверено, что GitHub принял коммит `f45ebe0`. Локальный просмотр последнего обновления проверялся на `http://127.0.0.1:8794/` на исходном компьютере. В новом чате эта ссылка заработает только при запущенном локальном сервере на том же устройстве.

**Следующий шаг.** Открыть `design-inspiration-library/index.html` из переданной папки или указанной ветки, выбрать любую карточку и сверить наличие блоков «Тип шрифта» и «Цветовая гамма». Обязательных доработок по последнему запросу не осталось. Если понадобится ссылка для открытия с другого устройства, отдельной задачей потребуется веб-хостинг.
