# Design Inspiration Library

Моя личная библиотека вдохновения. Здесь я собрал референсы веб-дизайна и айдентики, которые отражают мой визуальный вкус.

В коллекции 53 изображения и один ролик. Референсы сгруппированы по 13 визуальным стилям. В галерее можно искать работы, сохранять их в избранное и открывать оригиналы в полном размере.

В окне каждого референса есть разбор типографики и композиции, ключевые метки, три дизайнерских приёма и промпт из 5–7 предложений для своей версии. Подтверждённые шрифты указаны по источнику или по подписи на самом референсе, остальные названия приведены как визуально близкие аналоги.

В разборе отдельно указан тип шрифта и показана палитра из пяти оттенков с HEX-кодами. Цвета подобраны по изображениям, а для видео использован кадр предпросмотра.

Чтобы запустить библиотеку локально, скачайте папку целиком и откройте [index.html](index.html) в браузере.
