# Campus OS

[Открыть локальное сравнение](http://127.0.0.1:4180/). Верхняя панель переключает пять главных. На широких экранах ссылка «Открыть отдельно» выводит выбранный концепт на полный экран.

## Запуск

Для повторного запуска из этой папки нужен Node.js. Устанавливать пакеты не требуется.

```powershell
node server.mjs
```
