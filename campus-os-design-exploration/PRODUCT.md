# Campus OS

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

HTML, CSS и JavaScript. Локальный статический сервер на Node.js.

## Назначение

Конкурсный прототип для выбора визуальной системы университетской главной. Пять равноценных концептов помогают сравнить один сюжет о прикладном обучении, студенческих проектах и жизни кампуса.

## Аудитория

Содержание адресовано абитуриентам и студентам. В сравнительном режиме основная задача автора проекта или жюри состоит в том, чтобы просмотреть каждую главную целиком и выбрать визуальное направление.

## Возможности и ограничения

Общие русскоязычные вымышленные тексты, исходное видео пользователя, навигация по разделам. «Личный кабинет» служит обозначением входа для будущего этапа.

## Доступность

Линейная клавиатурная навигация, меню для узких экранов, статичный кадр при запросе уменьшенного движения, макеты от 360 px. На каждой странице есть дисклеймер конкурсного прототипа.
