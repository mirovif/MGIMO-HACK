# Сторонние материалы UTRET

| Компонент | Источник |
| --- | --- |
| Three.js | Текст лицензии MIT находится рядом с библиотекой в [`education-universe/vendor/LICENSE`](https://github.com/mirovif/MGIMO-HACK/blob/amvera/campus-os-design-exploration/education-universe/vendor/LICENSE). |

| Иллюстрации и видео | Происхождение ассетов указано в [SOURCES.md](https://github.com/mirovif/MGIMO-HACK/blob/amvera/campus-os-design-exploration/assets/SOURCES.md). Права на предоставленный ролик команда подтверждает отдельно. |

Зависимости приложения указаны в `frontend/package-lock.json` и `backend/requirements.txt` ветки [`amvera`](https://github.com/mirovif/MGIMO-HACK/tree/amvera).
